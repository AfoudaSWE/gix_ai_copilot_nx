# Roadmap

The project was built in twelve sequential phases; each was started only on explicit
instruction (see the `phase-gate` skill). Authoritative status:
[PROJECT_STATUS.md](PROJECT_STATUS.md).

| Phase | Scope | Record |
| --- | --- | --- |
| 01 | Foundation, protocol, core | [phase-01](phases/phase-01/) |
| 02 | LLM runtime, providers, streaming | [phase-02](phases/phase-02/) |
| 03 | React Copilot SDK and UI | [phase-03](phases/phase-03/) |
| 04 | Application context and shared state | [phase-04](phases/phase-04/) |
| 05 | Tools and agent actions | [phase-05](phases/phase-05/) |
| 06 | Generative UI and shared state | [phase-06](phases/phase-06/) |
| 07 | Enterprise security and HITL | [phase-07](phases/phase-07/) |
| 08 | OpenAPI, MCP, integrations | [phase-08](phases/phase-08/) |
| 09 | Knowledge, RAG, memory | [phase-09](phases/phase-09/) |
| 10 | Agents, multi-agent, workflows | [phase-10](phases/phase-10/) |
| 11 | DevTools, testing, evals, observability | [phase-11](phases/phase-11/) |
| 12 | Production platform and ecosystem | [phase-12](phases/phase-12/) |

Phase 12 is the last phase of this roadmap. Work beyond it (for example more provider
adapters, a hosted identity integration, a marketplace) would be a new roadmap and needs an
explicit decision; nothing here commits to it.
